🐉 DM Toolkit — How to Use

Party sheet, combat tracker, dice roller and SRD reference. Data saves in this browser.

Quick start

  1. Add heroes and edit names, classes and stats.
  2. Roll for Player Order, or move combatants with ▲/▼.
  3. Add monsters/NPCs. On each turn, roll, update HP/resources, then End Turn.

Header and session controls

  • Add Player adds a hero. Campaign switches or creates named local campaign saves.
  • Export/Import back up or restore party JSON. Optional timed auto-backup downloads a new JSON file every 10 minutes while open. Clear removes players. Reset App warns and confirms before clearing saved state.
  • Undo reverses recent supported edits. Print opens the browser print dialog. How to Use opens this guide.
  • Session Notes & Loot expands editable campaign notes and loot/gold log. Hide optional compacts optional controls. Theme/Text toggles light appearance and larger type. Sound is an optional saved preference (audio playback is not yet implemented). Auto-backup downloads a JSON backup every 10 minutes while this page is open.

Party & Combat

  • Rows track name, class, level, AC, HP, speed, initiative, passive perception, six abilities, temp HP, death-save marks, conditions, resources and notes. Name/class are editable before rolling order.
  • Ability modifiers calculate automatically. Roll Check rolls d20 plus the selected ability; Roll Skill maps each standard skill to its usual ability. Use the condition quick-pick to append a standard condition, or edit the field directly. Resources and notes are editable text.
  • Temp HP is displayed separately and is consumed before HP when damage is applied. Death-save success/failure buttons count to three; minus buttons correct a mark.
  • Add Monster/NPC searches the SRD online or adds a custom creature with HP, AC and initiative modifier. An SRD monster's Add to Combat button imports it.
  • Roll for Player Order rolls d20 plus each Init modifier and places highest first; tied totals reroll. ▲/▼ manually rearrange. End Turn advances and increments the round on wrap.
  • Undo stores a short local history of supported actions. Use Campaign to separate session parties.

Dice, checks and presets

  • Roll 1–20 individual dice of d4, d6, d8, d10, d12, d20 or d%. Set All changes all selected dice. Add a modifier.
  • Each player's last dice configuration is saved on their roll and restored when selected. Edit it before rolling to change it.
  • Roll Presets saves named expressions per player, e.g. 1d20+5. Choose Roll to repeat or Delete to remove.
  • Adv/Dis rolls two d20s, keeping higher/lower. Select an ability and use Roll Check for d20 + ability modifier.
  • Mouse wheel over numeric fields adjusts ±1; Shift adjusts ±10. History records rolls and turns.

DM Guide

  • Browse SRD monsters, spells, classes, races, rules, equipment, magic items and more online. Search and monster challenge-rating filter are available.
  • Monster details include abilities, actions and traits, plus Roll HP, Roll initiative and Add to Combat.
  • Links to official player and DM books are provided; copyrighted book text is not reproduced.

Saving & limits

  • Changes save locally in the current browser. Export parties regularly for backup; clearing browser data may remove them.
  • Campaigns, round, history, order, per-player dice, presets, resources, session notes and loot notes are kept in local storage. Print uses your browser's print dialog.
  • Character import accepts this app's party JSON; other formats may need conversion.
  • Audio playback is not implemented yet. Auto-backup creates browser downloads every ten minutes while enabled and the app stays open.
